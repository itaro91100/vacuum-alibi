# The Vacuum's Alibi

One line, 100 characters, in which a robot vacuum explains why it missed
a spot — for [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) on make.fun.

> Cliff sensor flagged the spot as stairs. I do not vacuum stairs. My warranty does not cover heroics.

## Why this one

The joke is a sensor report that escalates into a labour dispute. The
vacuum is deadpan and a little smug about its own hardware — its cliff
sensor did its job, the spot simply got misclassified as stairs — and then
it hides behind its warranty, as if falling down stairs were a workplace
hazard it never signed up for. Three short sentences, each one doing a
job: the misreading, the refusal, and the punchline about heroics.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes exactly the alibi text to `/output/entry.txt` — no
trailing newline, no extra text. The line is 100 characters, under the
200-character limit.
